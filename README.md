# Yoba 🇳🇬

Yoba is a Yoruba learning mobile app built with React Native (Expo).

## Features

- Learn Yoruba words and phrases
- Audio pronunciation
- Quiz system
- Daily streak tracking
- Cultural insights & proverbs

## Tech Stack

- React Native (Expo)
- TypeScript
- Expo Router

## Getting Started

```bash
npx create-expo-app yoba
cd yoba
npm install
npm start
```
